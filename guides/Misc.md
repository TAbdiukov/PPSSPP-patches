# Miscellaneous cheats

## Fired Up (PSP) - Undocumented Cheat

I found an **undocumented cheat** in *Fired Up*.

Set your player name to either:

`QQQQQQQQ` (`Q × 8`)

or:

`HHHHHHHHH` (`H × 9`)

This enables:

* God mode
* Infinite ammo
* Full story unlock

The game appears to check whether the ASCII values of your name add up to **648**:

Pretty wild that this was just sitting in the game undocumented.
